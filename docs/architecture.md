# アーキテクチャ設計・全体仕様

## ゲームジャンル・目的
- モンスター育成＆レースゲーム（PC向け）
- プレイヤーはモンスターを育成し、レースやショップ、トレーニング等を通じて進行

## 主要機能
- モンスター管理（育成・成長・スキル習得・交配）
- レース（参加・順位決定・報酬獲得・成績記録）
- ショップ（経験値アイテム・スキル習得）
- トレーニング（能力強化・成長値増加）
- 設定（音量・画面・言語・キーコンフィグ等）
- セーブ/ロード（JSONによる全体保存）
- サウンド（BGM/SE、音量・再生制御）
- 実績・トロフィー（レース勝利・育成達成等）
- UI（UI Toolkitで全画面統一）

## 必要アセット一覧

### モンスター関連
- モンスター本体スプライト（例: Dragon.png など）
  - 各種族・バリエーションごとに1枚以上
  - 配置: Assets/Art/World/
- アニメーション（AnimatorControllerやSpriteSheet）
- スキルアイコン（各スキルごとに1枚）
  - 配置: Assets/Art/UI/Skills/
- サムネイル・顔アイコン（一覧・選択用）
- ScriptableObject: モンスター種族・スキル定義

### レース関連
- レース背景画像（コースごとに1枚）
  - 配置: Assets/Art/World/Backgrounds/
- ゴール演出・順位表示用画像
- レースUIアイコン（順位・参加費・報酬など）

### スキル関連
- スキルアイコン（上記）
- スキル説明テキスト（ScriptableObjectやリソースファイル）

### ショップ関連
- 商品アイコン（経験値アイテム、スキル習得）
- UIボタン画像（購入ボタン等）

### UI/共通
- 画面背景画像（各画面ごと）
- ボタン・パネル・ラベル用UIパーツ
- 実績・トロフィーアイコン
- フォント（日本語対応）

### サウンド
- BGM（ゲーム進行・画面ごと）
- SE（ボタン・レース・購入・スキル習得等）
  - 配置: Assets/Art/Sound/

## アセット命名規則・管理
- 英語・キャメルケース、用途・種別・IDを明記
- 配置場所はAssets/Art/以下で機能・用途ごとに整理
- ScriptableObjectで種族・スキル・アイテム・レース定義を管理
