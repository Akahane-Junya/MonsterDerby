# UI設計・命名・スタイル統一ルール

## 画面構成
- 全画面UI Toolkit（UXML/USS）で実装
- 主要画面：TitleView, HomeView, ShopView, TrainingView, SettingsView, ...
- 画面比率16:9、基準解像度640x360

## 命名規則
- id/クラス名は英語・キャメルケース
- VisualElementはname属性で明示

## デザイン・スタイル
- 配色: 金色(枠線), 紺/紫(背景), 黄色(タイトル), 白/薄黄(ラベル)
- 角丸: 8px, ボタンは12~15px
- 余白: padding/gapで画面内に収まるよう調整
- フォント: 標準+太字、ラベルは日本語
- ボタン: 明確な動詞、横並びはgapで間隔調整

## 主要UI要素
- 設定画面: スライダー（音量）、トグル（フルスクリーン）、ドロップダウン（解像度/言語）、ボタン（適用/リセット/閉じる）
- ShopView: 商品リスト、所持金、購入ボタン
- 共通: 背景画像、暗幕オーバーレイ、ヘッダー

# UI設計・画面仕様

## 画面一覧・役割
- TitleView: タイトル・ゲーム開始
- HomeView: 拠点・各機能へのハブ
- ShopView: 経験値アイテム・スキル習得の購入
- TrainingView: モンスター育成・トレーニング選択
- SettingsView: 各種設定変更
- RaceView: レース参加・結果表示
- StatusView: モンスター詳細・成長確認
- AwardsView: 実績・トロフィー一覧
- BreedingView: モンスター交配・新規生成

## 各画面のUI要素・操作フロー
- ShopView: 経験値アイテム・スキル習得ボタン、所持金表示、忘却UI
- TrainingView: モンスター選択、トレーニング種別選択、実行ボタン、成長値表示
- RaceView: レースリスト、参加モンスター選択、参加費・報酬表示、順位・結果表示
- StatusView: モンスター能力値・スキル・成長履歴
- BreedingView: 親モンスター選択、新規モンスター生成、継承スキル表示

## デザイン・操作性
- 配色・余白・角丸・フォントは全画面統一
- 画面比率16:9、基準解像度640x360
- ラベルは日本語、ボタンは明確な動詞
- キーボード/マウス操作両対応
- アクセシビリティ考慮（色覚対応・フォントサイズ調整）
